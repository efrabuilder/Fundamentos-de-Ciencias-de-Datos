Datos · Algoritmos · Herramientas

¿Qué es un Dato?

Valor individual = Algoritmo + Información

Tipos de Datos — por naturaleza

Variable: característica observada o medida

Cualitativos (categóricos):

  • Nominal — sin orden (ej. color, sexo)
  • Ordinal — con orden (ej. satisfacción)

Cuantitativos (numéricos):

  • Discreto — contable (ej. nº de hijos)
  • Continuo — medible (ej. peso, tiempo)
Tipos de Datos — por privacidad

Públicos — accesibles legalmente por cualquiera. Ej. nombre en registro civil, precio de acciones

Privados / Sensibles — protegidos, de la intimidad. Ej. historial médico, contraseñas, ingresos

PII (Personally Identifiable Information): dato que te identifica directamente (cédula, pasaporte)

Un dato puede ser discreto y público, o discreto y privado — la naturaleza indica cómo procesarlo, la privacidad indica cómo protegerlo

Tipos de Datos — en programación
  • Cadena / String — texto (ej. "Hola")
  • Booleano / Bool — Verdadero / Falso
  • Entero / Integer — número sin decimales
  • Flotante / Float — número con decimales
  • Lista / Array — colección ordenada de datos
  • Nulo / Null (None) — ausencia de valor

(equivalentes en Python, SQL y la mayoría de lenguajes)

Tipos de Datos — por estructura

Estructurados — tablas, filas y columnas fijas. Ej. SQL, Excel, bases de datos relacionales

Semiestructurados — etiquetas, sin esquema rígido. Ej. JSON, XML, NoSQL, logs, respuestas de API

No estructurados — sin formato ni esquema. Ej. texto libre, imagen, audio, video, posts

(esta es la base de la "Variedad" del Big Data)
Empresas como Netflix, Facebook y Amazon combinan los tres tipos para generar valor (ver columna 3)

Estructura y Formatos de Datos

Bases de datos (estructurados): SQL, Excel, Oracle, Cloud — se analizan y consultan con SQL

Datos semiestructurados: JSON, CSV, XML — organizados por fila y columna, sin tabla rígida

Se consultan mediante APIs · Bucket de datos: acceso por medio de vistas

IoT / Widgets — intercambio y movimiento de datos, no requieren tabla fija (No SQL)

Línea de Comandos SQL

Llamar tabla: USE "BASE_DATOS" GO

Palabra en azul = palabra reservada

Dato cuantitativo — números (edad, salario, ventas): promedio, máximo, mínimo, moda, suma

Dato cualitativo — cualidades (color, estado civil, opinión, marca, características)

CSV — valores separados por coma, compatible con todo y pesa menos

JSON — ideal para transportar datos entre apps y bases de datos · XML — "diccionario de datos"

Tablas → filas, columnas, datos, llaves primarias/foráneas y relaciones

3. BIG DATA, BI, IA Y ML

Módulo 3

Inteligencia de Negocios (BI)

Definición

Se enfoca en recopilar, organizar, visualizar y analizar datos históricos para apoyar decisiones empresariales mediante reportes e indicadores

Herramientas comunes

  • Power BI — integra Excel, Azure y modelos DAX
  • Tableau — visualizaciones muy interactivas
  • Qlik Sense — motor asociativo, explora libremente
Big Data

Definición

Se refiere al almacenamiento, procesamiento y gestión de volúmenes masivos de datos que superan la capacidad de las herramientas tradicionales

Herramientas comunes

  • Hadoop — almacenamiento distribuido (HDFS)
  • Spark — procesamiento en memoria, muy rápido
  • AWS / GCP / Azure — data lakes en la nube
Inteligencia Artificial (IA)

Definición

Campo de la informática que busca crear sistemas capaces de simular el razonamiento y comportamiento humano para resolver problemas complejos

Herramientas comunes

  • TensorFlow/PyTorch — frameworks de redes
  • ChatGPT / OpenAI — modelos generativos
  • Modelos de visión y NLP — leen imagen/texto
Machine Learning (ML)

Definición

Subcampo de la IA en el que los sistemas aprenden patrones a partir de datos, sin ser programados explícitamente para cada tarea

Herramientas comunes

  • Scikit-learn — algoritmos clásicos en Python
  • TensorFlow/PyTorch — también usados en ML
  • XGBoost — árboles, muy usado en competencias
Línea de Tiempo Evolutiva
  • 1662 — J. Graunt: 1er análisis estadístico de datos [7]
  • 1865 — Primer uso del término "Business Intelligence" [5]
  • 1890 — Hollerith: máquina tabuladora (censo EE.UU.)
  • 1959 — Nace el término "Machine Learning" (A. Samuel)
  • 1989 — Dresner (Gartner) formaliza el BI moderno
  • 2001 — D. Laney define las 3 V's del Big Data [4]
  • 2010 — Boom del Machine Learning (cómputo + datos)
  • 2020 — Arranca la ola de IA Generativa (GPT-3)

Nota: el BI se popularizó como término en 1989, no en 1980 — sus raíces (DSS) sí vienen de esa década.

Las 5 V's del Big Data [4][6]
  • Volumen — cantidad masiva de datos
  • Velocidad — rapidez de generación/análisis
  • Variedad — texto, imagen, audio, video
  • Veracidad — confiabilidad, sin errores
  • Valor — utilidad para decisiones

3 V's originales (Laney, 2001): Volumen, Velocidad, Variedad — Veracidad y Valor se agregaron después

Conceptos Relacionados

IA Generativa

Modelos que crean contenido nuevo (texto, imagen, audio, código) a partir de patrones aprendidos. Ej. ChatGPT genera texto; DALL-E genera imágenes

Deep Learning

Subcampo del ML basado en redes neuronales de múltiples capas, inspiradas en el cerebro humano. Permite procesar datos complejos: imagen y voz

Diferencias Clave: Ciencia de Datos vs. BI vs. Big Data vs. IA vs. Machine Learning

Tienen propósitos similares, pero NO son lo mismo

Confusión 1: pensar que todo es lo mismo

Realidad: cada uno responde una pregunta distinta

Confusión 2: creer que IA = Ciencia de Datos

Realidad: la Ciencia de Datos usa la IA como una herramienta más, no son lo mismo

Confusión 3: creer que Big Data es solo "una base de datos gigante" (es más que eso)

Realidad: también implica velocidad, variedad y valor, no solo volumen

Confusión 4: creer que Machine Learning = IA (ML es en realidad un subcampo de la IA)

Realidad: existe IA basada en reglas que no usa ningún tipo de Machine Learning

Ejemplos Reales de Big Data / BI

Netflix — recomienda contenido con ML sobre historial de reproducción (dato no estructurado)

Facebook / Meta — segmenta anuncios con datos de interacción social (texto, imagen, video)

Amazon — optimiza inventario y logística con datos estructurados de ventas en tiempo real

Google — indexa y prioriza resultados de búsqueda combinando Big Data + BI

Spotify — arma playlists personalizadas (Discover Weekly) con Machine Learning

Todos combinan datos estructurados, semi y no estructurados: la mezcla es lo que define "Big Data"

Uso responsable, transparente y justo de datos

Ciclo de Vida del Dato (CAPUAE)

Captura → Almacenamiento → Procesamiento → Uso/Compartición/Análisis → Archivo → Eliminación

Archivo: se guardan datos que ya no se usan pero se reservan para crear historial

Eliminación: al pasar el tiempo, si el dato ya no es útil política y éticamente, se elimina

Los logs registran todo el ciclo hasta destruirse
