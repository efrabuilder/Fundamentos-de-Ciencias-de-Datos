🧹 Limpieza y Transformación

Snippets esenciales para preparar tus datos antes de cualquier análisis o cruce.

1. Estandarizar texto (ideal antes de cruzar tablas)

Pasa todo a minúsculas y quita espacios fantasma a los lados.

# Limpieza de texto en una columna
df['columna'] = df['columna'].str.lower().str.strip()

2. Convertir texto a Fecha (Datetime)

Asegura que las fechas se traten como fechas y no como texto.

df['Fecha'] = pd.to_datetime(df['Fecha'])

3. Extraer mes y año de una fecha

Útil para agrupar ventas por periodo.

df['Mes'] = df['Fecha'].dt.month
df['Año'] = df['Fecha'].dt.year

4. Manejo de Nulos

Eliminar filas donde una columna clave esté vacía, o rellenar nulos con ceros.

# Eliminar filas sin ID de cliente
df = df.dropna(subset=['ID_Cliente'])

# Rellenar nulos de ventas con 0
df['Ventas'] = df['Ventas'].fillna(0)

5. Filtrar el Dataset

Quedarte solo con las ventas mayores a 1000, por ejemplo.

df_filtrado = df[df['Ventas'] > 1000]

🔗 Cruces Relacionales con pd.merge()

En Pandas usamos pd.merge() para replicar los JOINs de SQL. Siempre pregúntate: ¿Qué tabla manda?

✅ Left Join (el más recomendado para agregar dimensiones)

Mantiene TODAS las filas de la tabla de la izquierda (ej. Ventas) y solo trae los datos de la derecha (ej. Tiendas) que coincidan. Si una venta se hizo en una tienda que no existe en el catálogo, quedará con valores nulos (NaN).

df_final = pd.merge(
    df_ventas,
    df_tiendas,
    on='ID_Tienda',
    how='left'
)
💡
¿Cuándo usarlo? Cuando quieres conservar todas las transacciones y solo enriquecerlas con la información de la tabla de dimensión (catálogos, tiendas, productos, etc.).

⚠️ Inner Join (el restrictivo)

Solo mantiene las filas donde el ID_Tienda exista en AMBAS tablas. Cuidado: si lo usas, podrías perder registros de ventas sin darte cuenta.

df_final = pd.merge(
    df_ventas,
    df_tiendas,
    on='ID_Tienda',
    how='inner'
)
🚨
Peligro: El inner join puede eliminar filas silenciosamente. Siempre compara len(df_antes) vs len(df_después).

Ejecuta estos pasos antes de limpiar o transformar. Marca cada casilla a medida que avanzas.

print(df.shape)
df.info()

📌 Reglas de Oro

Resumen ejecutivo de buenas prácticas para tener siempre a mano.

Etapa Regla clave
Auditoría Siempre ejecuta df.shape, df.info(), df.isnull().sum(), df.duplicated().sum() y df.describe() antes de tocar nada.
Texto Aplica .str.lower().str.strip() antes de cualquier cruce.
Fechas Usa pd.to_datetime() siempre. Considera errors='coerce' para no romper el flujo.
Nulos Decide: ¿elimino (dropna) o relleno (fillna)? Depende del negocio.
Merge Pregúntate: ¿qué tabla manda? Si es Ventas, usa how='left'.
Llaves Mismo nombre exacto + mismo tipo de dato (ID numérico ≠ ID texto).
Inner Join ⚠️ Puede borrar ventas sin que te des cuenta. Úsalo con cuidado y verifica el conteo de filas.
🎯
Flujo recomendado: Auditoría → Limpieza → Estandarización → Transformación → Cruces → Auditoría final.
