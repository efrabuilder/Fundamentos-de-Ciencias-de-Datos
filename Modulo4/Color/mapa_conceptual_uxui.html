Mapa Conceptual — Análisis UX/UI del Dashboard de RRHH

Evaluación UX/UI

Dashboard "Planta / Grupo"

Aciertos de Diseño

Codificación cromática (semáforo)

Rojo/Verde/Ámbar en IFAR y Seguridad

Principio: Atributos preatentivos

Agrupación en tarjetas (chunking)

Cada KPI en panel propio con título

Principio: Proximidad y cierre (Gestalt)

Jerarquía visual por tamaño

Números grandes/bold vs. etiquetas pequeñas

Principio: Jerarquía visual / énfasis

Problemas de Diseño

Paleta de color sin sistema

Cada tarjeta usa un color de acento distinto

Principio violado: Consistencia visual

Gráfico de dona (4 segmentos)

Difícil comparar ángulos/áreas con precisión

Principio violado: Precisión perceptual (Cleveland-McGill)

Tabla "Ausentismo" sobrecargada

7 columnas, fuente pequeña, sin jerarquía

Principio violado: Ruido visual (Tufte)

Grid sin alinear

Paneles con alturas distintas, bordes sueltos

Principio violado: Alineación (Gestalt)

Correcciones Propuestas

Paleta neutra + color con significado

Grises/azul corporativo en encabezados; rojo/ámbar/verde solo para desempeño

Barras horizontales en vez de dona

Ordenadas de mayor a menor, con % al final de cada barra

Más espaciado + fila "Total" distinta

+4-6px entre filas, zebra striping marcado, columnas secundarias en detalle expandible

Grid de 12 columnas alineada

Cada tarjeta ocupa múltiplos exactos de columna/fila para alinear bordes

Leyenda de principios de diseño (UX/UI) aplicados en este análisis

Atributos preatentivos — el ojo detecta color/tamaño antes de leer texto
Consistencia visual — el color debe usarse con un sistema, no decorativo
Proximidad y cierre (Gestalt) — agrupar lo relacionado, separar lo distinto
Precisión perceptual (Cleveland-McGill) — longitud > ángulo/área para comparar
Jerarquía visual — tamaño/peso indican importancia del dato
Ruido visual / tinta-dato (Tufte) — minimizar elementos que no aportan info
Alineación (Gestalt) — los bordes alineados crean orden y estructura

Verde = Aciertos    Rojo = Problemas    Azul = Correcciones propuestas
